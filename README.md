# Go 200 Steps

Goを基礎から250ステップで学べる学習Webサービス。
各ステップは「解説→課題→コード編集→実行→答え合わせ」を1ページで完結できる。

公開URL：https://go-200-steps.pages.dev

## 特徴

- 25章×10ステップ=250ステップのカリキュラム（Hello Worldからゴルーチン・チャネル・総合演習、よくあるエラー50選まで）
- ブラウザ上のエディタでGoコードを編集し、その場でビルド・実行
- コンパイラのエラーメッセージをそのまま表示（エラーを読む訓練も学習の一部）
- 1から書かせず、例コードの部分修正・穴埋め・意図的なエラーの修正を中心とした課題設計
- ヒント（段階表示）、模範解答、期待出力と使用コードによる自動クリア判定
- 進捗はブラウザのlocalStorageに保存

## 必要環境

- Node.js 18以上（依存パッケージなし。npm install不要）
- Go（あればローカルでビルド・実行。なければGo Playground APIを利用するためインターネット接続が必要）

## 使い方

```bash
git clone https://github.com/MaitaTomoya/go-200-steps.git
cd go-200-steps
node server.js
```

起動するとターミナルにURLが表示されるので、ブラウザで開く（デフォルトは http://localhost:3940 ）。
ポートは環境変数PORTで変更できる。

```bash
PORT=8080 node server.js
```
